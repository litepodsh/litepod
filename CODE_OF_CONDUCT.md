# Code of Conduct

**English** · [Español](CODE_OF_CONDUCT.es.md)

We want Litepod to be a welcoming place to build and help. Be kind and assume good faith.

## Language

You can write in **English or Spanish, equally**. Use whichever you're more comfortable with.
Never make fun of someone's language skills.

## Not allowed

In issues, pull requests, discussions, or anywhere in this project:

- Racism, hate speech, or discrimination of any kind
- Harassment, threats, or personal attacks
- Sexualized language or imagery
- Spam, trolling, or insulting/derogatory comments

## Reporting

If you see a violation, report it privately to the maintainer
([@Sebasmzt](https://github.com/Sebasmzt)). Violations may result in being blocked from the
project.
